Detailed Description

: Header file for the ButtonToSwitch_ESP32 library's PressSignalSource interface implementation classes

The classes included implement the PressSignalSource interface class, allowing the ButtonToSwitch_ESP32 objects to accept different signals sources to evaluate the _isPressed attribute flag.
From the simplest project using the MCU GPIO pins as signal source, the project development might need to implement different sources for the signal, as MCU GPIO pins become used by other resources (GPIO expanders might be use as an alternative input pins source), as the the signal source might be too far for a MCU GPIO pin signal to get to the right value due to voltage drop or interfearence (a cabled or radio signal technology input solution might become mandatory), and others.
